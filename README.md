## Repository Update

This project was originally built using a microservices architecture. Since it is currently being developed and maintained by a single developer, the codebase has been migrated to a monorepo structure.

This change was made to simplify development, reduce operational complexity, improve maintainability, and allow for faster iteration while working as a solo developer.

The long-term architecture and vision of the project remain unchanged, and the codebase can be separated into independent services again in the future if scaling requirements demand it.
